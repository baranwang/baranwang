可扩展的开源AI邮件客户端，覆盖macOS / Windows / Linux，将邮件收发与AI助手整合在同一产品中。

- 基于Go / MyGo原生界面与React嵌入页面，支持IMAP / SMTP、多账号同步、离线操作与全文搜索。
- AI助手支持邮件问答、附件阅读、摘要、翻译与回复草拟；通过Skills、TypeScript插件与MCP扩展能力，并兼容云端及本地模型。
- 以权限声明、操作审批与系统钥匙串保护邮件和凭据；提供Local API与MCP服务，外部Agent仅可读取邮件与创建草稿，邮件发送须由用户确认。
