本地 AI 网关：一个端点同时服务 OpenAI / Anthropic / Gemini 协议的客户端，后端支持 API Key 与多种账号接入方式。

- 透明协议转换、多 Provider 路由与故障回退、额度感知的候选选择、插件扩展，以及请求量、Token、费用与链路追踪等可观测能力。
- 产品形态覆盖 CLI、托管服务、Web Dashboard 与 macOS / Windows / Linux 桌面客户端；一条命令即可把 Claude Code、Codex、OpenCode 等 Agent 接入网关，并支持安全回滚。
- 以 Agent 协作方式持续交付：Issue → PR → Agent Review → Changesets 自动发版，已发布 **70+** 个版本。
