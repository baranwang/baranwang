本地AI网关：一个端点同时服务OpenAI / Anthropic / Gemini协议的客户端，后端支持API Key与多种账号接入方式。

- 透明协议转换、多Provider路由与故障回退、额度感知的候选选择、插件扩展，以及请求量、Token、费用与链路追踪等可观测能力。
- 产品形态覆盖CLI、托管服务、Web Dashboard与macOS / Windows / Linux桌面客户端；一条命令即可把Claude Code、Codex、OpenCode等Agent接入网关，并支持安全回滚。
- 以Agent协作方式持续交付：Issue → PR → Agent Review → Changesets自动发版，已发布**70+个**版本。
